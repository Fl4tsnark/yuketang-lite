# 雨课堂实时作答监控与 AI 答题助手

一个面向雨课堂网页版的 Tampermonkey 用户脚本。脚本只读监听课堂实时通道，在老师发布题目时提供提醒，并可调用用户配置的 OpenAI 兼容接口生成参考答案。

> 本项目不会自动选择或提交答案，不会修改雨课堂的上行请求。AI 输出仅供学习对照，请自行核验并遵守所在学校的课堂与考试规范。

## 功能特性

- **实时捕获**：监听 WebSocket，并通过 Fetch、XHR 和页面状态补全题目与课件信息。
- **多端提醒**：支持提示音、桌面通知、标签页标题闪烁和可选的 ntfy 手机推送。
- **AI 参考答案**：支持文本题与图片题，可自动识别，也可手动重新识别。
- **图片题回退**：优先向视觉模型传递图片 URL；模型无法访问时转为内存 base64 重试，不写入磁盘。
- **兼容接口**：内置 OpenAI、DeepSeek、智谱 GLM 预设，也支持自定义 OpenAI 兼容 Base URL。
- **模型管理**：支持拉取 `/models` 列表、下拉选择或手动输入模型名。
- **会话回看**：保留当前页面会话内最近 3 道题及其 AI 结果，关闭页面后自动清空。
- **调试与自检**：提供通知测试、模拟来题、课堂数据检查、AI 链路测试和原始帧调试日志。

## 安装

先为浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)，然后点击：

**[安装脚本](https://raw.githubusercontent.com/Fl4tsnark/yuketang-lite/main/yuketang-lite.user.js)**

Tampermonkey 会自动打开安装确认页。安装完成后进入[雨课堂网页版](https://www.yuketang.cn/)，看到右下角的“雨课堂助手”悬浮条即表示加载成功。

脚本支持从仓库检查后续更新。若浏览器中已有同类雨课堂脚本，建议先停用，避免重复提醒。

## 使用说明

1. 上课前在电脑浏览器中登录雨课堂网页版，并保持课堂页面打开。
2. 点击悬浮条进入设置，按需开启提示音、桌面通知、标题闪烁或 ntfy。
3. 如需 AI 参考答案，配置接口预设、API key 和模型。
4. 使用“测试通知”“测试答题”或“模拟来题”检查配置。
5. 老师发布题目后，可在悬浮面板中查看题目、识别状态和参考答案。

### AI 配置

| 配置项 | 说明 |
| --- | --- |
| 接口服务 | OpenAI、DeepSeek、智谱 AI 或其他兼容接口；默认不预选 |
| 接口地址 | 选择其他兼容接口时填写 OpenAI 兼容地址 |
| API key | 仅保存在 Tampermonkey 本地存储中 |
| 模型 | 默认留空，可手动填写或从接口获取列表；图片题需选择支持视觉输入的模型 |
| 自动识别 | 关闭后仍会正常提醒，可在题目详情中手动识别 |

部分兼容接口不提供 `/models`。遇到模型列表获取失败时，可直接手动填写模型名。

从旧版升级时，未填写 API key 且仍使用旧默认智谱配置的安装会自动恢复为空白配置；已经主动配置过的接口不会被覆盖。

### ntfy 配置

1. 在手机安装 [ntfy](https://ntfy.sh/) 并订阅一个不易猜测的 topic。
2. 在脚本设置中启用 ntfy，填写服务器地址和相同的 topic。
3. 点击“测试推送”验证配置。

topic 相当于接收凭据，请勿公开分享。

## 匹配站点

```text
*://yuketang.cn/*
*://*.yuketang.cn/*
```

覆盖雨课堂主站及其子域名，包括使用雨课堂域名部署的学校站点。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `GM_getValue` / `GM_setValue` | 读取和保存本地设置 |
| `GM_setClipboard` | 复制答案和调试日志 |
| `GM_notification` | 发送桌面通知 |
| `GM_xmlhttpRequest` | 请求 AI 接口和 ntfy 服务 |
| `GM_registerMenuCommand` | 注册 Tampermonkey 菜单命令 |
| `unsafeWindow` | 在页面上下文安装只读监听钩子 |
| `@connect *` | 支持用户自定义 AI 与 ntfy 服务地址 |

## 开发与测试

项目无运行时依赖。安装 Node.js 后执行：

```bash
node --check yuketang-lite.user.js
node test/test-core.mjs
```

测试覆盖课件解析、实时推题捕获、历史基线、事件去重、AI 请求结构、答案解析与题型映射。

## 数据与隐私

- API key 和设置保存在 Tampermonkey 本地存储中。
- 题目与 AI 结果仅保存在当前页面内存中。
- 图片题可能被发送至用户配置的 AI 服务商。
- 启用 ntfy 后，通知内容会发送至用户配置的 ntfy 服务。
- 调试日志可能包含课堂实时帧，分享前请检查其中是否含有敏感信息。
